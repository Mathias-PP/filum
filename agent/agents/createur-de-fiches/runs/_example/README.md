# Run d'exemple

Ce dossier est un **modèle**. Ne pas travailler dedans. Pour créer une vraie fiche :

```
cp -r agent/agents/createur-de-fiches/runs/_example agent/agents/createur-de-fiches/runs/<slug>
```

Puis :

1. Éditer `runs/<slug>/00_brief.md` (copie de `setup/questionnaire.md`).
2. Passer les étapes 1 à 7 dans l'ordre, chaque étape lit son `CONTEXT.md`.
